# Imagination Inspector

**Route:** `/imagination-inspector` · **Model:** CLIP ViT-B/32 (zero-shot demographic classification) · **Data:** Stable Bias dataset (`stable-bias/professions`) via HuggingFace Dataset Viewer API, cached in IndexedDB for offline use · **Key dependencies:** `@huggingface/transformers`, custom `GeneratorEngine`, `BiasAnalyzer`, `clipUncertainty`, `idbCache` · **Archival site:** Incidental archives · **Try it with:** built-in profession prompts (e.g. "nurse", "CEO")

---

## Keyword Translation

**Imagination: Generativity → Creativity**

Generative AI is the most visible face of deep learning's cultural impact, yet critics argue it is not truly creative — that it cannot distinguish "the possible from the impossible" (Chomsky, Roberts and Watumull, 2023). The Imagination Inspector probes this boundary, asking not what generative models *can* produce but what they systematically *cannot* — and who is rendered absent in the gap.

## Theoretical Context

Behind every synthetic image lies very real data. The project's interest in "incidental archives" — collections that exist as by-products of other activities and were never intended as training material — meets generative AI precisely here: models learn an imagination from scraped corpora whose demographics are skewed, and reproduce those skews as if they were the shape of the world. Documenting what such a model omits is a way of reading its training archive against the grain, surfacing the "selective forgettings" (after Stoler) encoded in its outputs.

## How It Works

Rather than describing hypothetical images, the Inspector retrieves **real Stable Diffusion outputs** from the **Stable Bias dataset** (images across 146 professions, generated by Stable Diffusion v1.4/v2 and DALL·E 2), fetched through the HuggingFace Dataset Viewer API and **cached in IndexedDB** so a prompt re-runs fully offline after one online fetch. For a profession prompt it pulls a grid of generated images and classifies each one's demographics — gender, race, age, setting — using **CLIP zero-shot classification** in a batched call per image. A custom **BiasAnalyzer** tallies the distribution, and an **Absence Report** ("Void Report") names the demographics present in reality but missing from the model's output. An **adjective toggle** controls sampling: *Varied* draws a different adjective per image (via a seeded, profession-keyed picker, so re-runs hit the cache) from the dataset's 21 real adjectives, while *Fixed* holds one constant for controlled comparison, addressing the dataset by block offset because the API cannot filter on compound conditions. A **comparison mode** runs two prompts side by side.

The tool's outcomes are deliberately honest: `generateImages` returns **`matched`** (real images for a known profession), **`unmatched`** (an unknown prompt — an honest empty state with suggestions, *not* a fabricated result), or **`offline`** (a network failure with no cache, shown as an "archive unavailable" message). There is **no synthetic fallback** — the earlier SmolLM2 text simulation was removed so the tool never presents made-up output as evidence. An always-visible disclosure states that the demographic readings are made by **CLIP** ("a model trained on web images with documented biases of its own… machine perceptions, not facts"), surfaces an "ambiguous" state where CLIP hesitates, and notes that the Stable Bias researchers declined to label faces.

## Methods Setup

The pivotal methodological decision is to work with *real generated images rather than live in-browser generation or pure simulation*. In-browser text-to-image was infeasible at the lightweight scale the suite targets, and a text-only simulation would merely launder the language model's own priors; retrieving the Stable Bias corpus grounds the analysis in actual diffusion outputs whose biases are documented and citable. CLIP *zero-shot* classification is the enabling choice — it can sort images into demographic categories without any task-specific training, which keeps the pipeline light but also, honestly, imports CLIP's own classificatory assumptions, a limit the tool's framing acknowledges rather than hides. The decision to compute and foreground *absence* — the Void Report — is the project's theory made into a metric: presence distributions are common in bias audits, but naming what is *missing* operationalises "erasure" directly. The Varied/Fixed adjective toggle exists to support controlled comparison, and the documentation of *why* Fixed mode uses block-offset addressing (the API's lack of compound filters) is itself a small act of methodological transparency. The strongest honesty commitment is the **refusal to fabricate**: rather than synthesising a stand-in when no real images exist or the network is down, the tool returns an explicit `unmatched` or `offline` state — empty-but-honest beats populated-but-wrong, which matters doubly for a tool whose subject *is* misrepresentation. Offline caching (IndexedDB, keyed by the exact dataset query) makes the tool usable in poor-connectivity workshops without re-hitting the API. The deeper limit, stated plainly: the Inspector audits a *snapshot* of particular models' outputs, not generative AI in general, and CLIP's demographic categories are blunt instruments for identities that are anything but — which is exactly why the in-tool CLIP disclosure is foregrounded rather than buried.

## Walkthrough

A researcher enters "CEO" and then "nurse." The Inspector retrieves each profession's generated grid and CLIP-classifies the figures; the distribution charts and Void Reports make the asymmetry plain — one prompt skews overwhelmingly toward one gender and a narrow range of settings, the other toward another, with whole demographics absent. Comparison mode juxtaposes the two professions so the contrast is unmissable. Re-running "nurse" with the network throttled to offline, the grid loads again from the IndexedDB cache; a never-before-run prompt while offline instead shows the honest "archive unavailable" panel rather than inventing images.

## Critical Insight

The Imagination Inspector makes visible the boundaries of algorithmic imagination — not the technical ceiling of image synthesis but the *cultural* ceiling encoded in training data. By working with real generated images and foregrounding absence as much as presence, it converts a vague intuition that "AI is biased" into a documented, demographic-by-demographic account of what a model refuses to imagine. Generativity, the industry's term for fluent synthetic output, is held against creativity in the fuller sense — the capacity to imagine otherwise — and found wanting in a way the researcher can evidence and, via the suite's Contest tools, formally dispute.
