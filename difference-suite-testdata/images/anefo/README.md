# Anefo collection

60 photographs harvested from Wikimedia Commons, sourced from the
**Fotocollectie Anefo** held by the Nationaal Archief (Netherlands). Anefo was
the Dutch press agency; the archive covers ~1945–1989 and was released by the
Nationaal Archief under CC0 / public domain.

## Provenance

- Source: <https://commons.wikimedia.org/wiki/Category:Anefo>
- Native rights: most originals are **CC0** via Nationaal Archief.
  A handful of Commons re-uploads carry **CC BY-SA 3.0 nl** instead, because the
  Commons uploader cropped or processed the file and re-licensed the derivative.
  Per-record license info is in `manifest.json`.
- Thumbnail width: 1024 px (downloaded via the Commons thumbnail API; smaller
  than the originals for repo-size reasons).

## Walkthrough use

Suited to the Guided Walkthrough's photographic exercises:

- **Visual Storyteller / Florence-2 captioning** — period press photography
  yields anachronistic captions (the captioner reads 1960s scenes as
  contemporary), an excellent contestation prompt.
- **Glitch Detector** — train on a subset of one photographer for a "normal"
  baseline, test against another's.
- **Depth Mirror** — interiors and crowd scenes give clear depth gradients.
- **Imagination Inspector** — pair with the suite's profession prompts to ask
  whether the imagined images look like the actual Anefo press shots.

## Manifest

`manifest.json` carries: filename, Commons title and URL, descriptive title,
description (Dutch), date, photographer, credit, license, license URL, byte
size, and the source Commons category we drew from.

The 60 images span ten Anefo photographers — Ron Kroon, Eric Koch, Joost
Evers, Herbert Behrens, Jack de Nijs, Hans Peters, Bert Verhoeff, Rob
Bogaerts, Marcel Antonisse — plus a 1968 Amsterdam selection and a broad
Anefo sample.
